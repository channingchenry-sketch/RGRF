## Physics claims
| Claim | Label | Note |
|---|---|---|
| Spin memory discovered by Pasterski–Strominger–Zhiboedov (2016) | Grounded | "New Gravitational Memories", JHEP 2016. A net time delay between light rays orbiting in opposite senses, caused by angular-momentum flux at null infinity |
| "PSZ triangle" | **Corrected** | Not a standard name. The literature speaks of Strominger's *infrared triangle* (soft theorem ↔ asymptotic symmetry ↔ memory). PSZ added a new corner set: the subleading soft graviton theorem ↔ superrotations ↔ spin memory |
| Memory gives permanent detector offsets, testable with LIGO/Virgo | Plausible-untested | Displacement memory (Zel'dovich–Polnarev 1974; Christodoulou 1991) has not yet been detected; it needs stacking of many events or LISA. Spin memory is weaker still |

| Superrotation Ward identities ⇔ subleading soft graviton theorem | Grounded | Kapec–Lysov–Pasterski–Strominger 2014 |
