## Key findings
1. The aerobic-fungus vs anaerobic-Geobacter mismatch is the real constraint; Shewanella is the easy partner.
2. Cross-feeding (lactate → acetate) is established; Geobacter–Shewanella DIET is not.
3. Nanowire identity (cytochrome vs e-pili) is still debated.
4. An algal barrier would oxygenate the Geobacter zone if lit.
